### Fixed

- Carry and `togi reset --all` treat the state directory path literally, so a path containing `[`, `*`, `?` or `\` no longer makes carry fail or silently skip older archived sessions, and no longer hides pending archive or carry markers from `reset --all`. If your state directory path contains one of these characters and a session carried evidence across a ruleset, schema or evidence-epoch transition, run `sudo togi --state-dir <path> reset --core N` with that state directory as `<path>` for every tuned core; the journal cannot show which archives carry skipped.
