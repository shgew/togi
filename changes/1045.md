### Changed

- `togi run` reports a signal listener that cannot start by its failed step, such as `start the signal listener: register the signal handlers: <cause>`, instead of `listen for signals: <cause>`.
- `togi emergency-stop` reports a failed zero write as `16 of 16 cores did not read back 0: set every core to 0: <cause>`.
- A dashboard thread that cannot start is reported as `dashboard: spawn the dashboard thread: <cause>; printing events instead`.
