### Changed

- `just bench` audits the journals of every simulated run, names each run that breaks a check, does not cache it and exits 1; a run that reaches the boot cap is audited as unfinished and is no longer a violation.

### Removed

- The `just audit` sweep and its `--seeds`, `--jobs`, `--suite`, `--timeout`, `--keep`, `--records`, `--root`, `--bench` and `--sim` flags, with its wall-time and bench-status checks: `just audit` audits the state directories it is given.
