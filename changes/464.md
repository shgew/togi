### Changed

- A failure at CO 0 ends tuning only after the failing trial, rerun with every core at CO 0, fails too; if that rerun passes, the failure goes to the cores off CO 0 instead. A failure whose profile was already all at CO 0 still ends tuning at once.
- A failure point at CO 0 carried from an older ruleset's session gets the same all-zero rerun before tuning ends.
