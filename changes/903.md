### Changed

- togi is now written in Rust and starts a fresh session: before the first boot, move `/var/lib/togi` to `/var/lib/togi-go`; see [Go to Rust cutover](https://github.com/shgew/togi/blob/main/docs/howto.md#go-to-rust-cutover) for the full steps and the rollback.

### Fixed

- A new `state.rebuilt` event names each top-level `facts` key that differs, such as `last_seq`, instead of `facts`, so the audit no longer flags a snapshot left behind by a crash as disagreeing with the current state.
