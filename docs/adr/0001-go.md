# Go as the implementation language

togi coordinates hardware and processes: it writes sysfs files, launches and signals stress programs, parses their output and writes a journal. Speed is irrelevant, because the backends do the heavy work. Go was chosen over Rust: seconds-long compiles and `go test` result caching keep agent edit-test loops fast, `gofmt` leaves one style, and the owner already packages Go with `buildGoModule`.

## Considered Options

- **Rust:** exhaustive enums fit the tuner state machine better. Rejected for slower compiles, no test-result caching and a new packaging convention. The `exhaustive` linter covers most of the gap for Go switch statements.

## Consequences

The future TUI uses the Charm stack (Bubble Tea); Ratatui was judged equivalent, so language choice did not depend on it.
