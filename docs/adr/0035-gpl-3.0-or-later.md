# License togi under GPL-3.0-or-later

togi was published under the MIT license. MIT lets anyone take the tuner, change it and ship the result as a closed program, with the copyright notice as the only obligation. togi is shared for free, and the intent is that work built on it is shared the same way.

## Decision

License togi under the GNU General Public License, version 3 or any later version (SPDX `GPL-3.0-or-later`), starting with the release after 0.9.0. `LICENSE` holds the license text, the README states the copyright and license, and the Nix package declares `lib.licenses.gpl3Plus`.

## Considered Options

- **Keep MIT:** rejected. It permits closed redistribution of changed versions, which is the outcome this decision exists to prevent.
- **GPL-3.0-only:** rejected. "Or any later version" lets togi follow future GPL revisions without another relicensing.
- **AGPL-3.0:** rejected. Its extra obligation covers software users reach over a network; togi is a local command-line tool, so the clause adds friction for packagers without covering any real use.
- **MPL-2.0:** rejected. Its file-level copyleft lets togi be combined into a closed program, as long as togi's own files stay open.
- **GPL-3.0 with an additional attribution term (section 7(b)):** rejected. The plain license already requires keeping the copyright notices and marking changed versions as changed, and an extra term makes togi harder to package and reuse.
- **A license restricting harmful or privacy-invading uses:** rejected. Such licenses are not open source, are avoided by distributions and are hard to enforce. togi protects privacy by design instead: it runs locally and sends nothing anywhere.

## Consequences

Releases up to and including 0.9.0 stay available under MIT; a license already granted cannot be withdrawn. From the next release, anyone who distributes togi or a changed version must do so under GPL-3.0-or-later and make the corresponding source available. Running or changing togi privately carries no obligation.

Every dependency is under MIT or BSD-3-Clause, both compatible with the GPL. mprime and y-cruncher run as separate processes, and `ryzen_smu` is reached through sysfs, so neither constrains togi's license. Ideas taken from linux-corecycler, itself GPL-3.0 ([ADR 0002](0002-clean-room-rewrite.md)), no longer carry a license mismatch.

All of togi's copyright is held by its maintainer, which made this change possible without anyone else's consent. Once outside contributions are accepted, relicensing again would need every contributor's agreement unless contributions come under an agreement that allows it; that choice belongs with opening contributions at 1.0.
